# Lab 5 – Persona and WordPress



#### Overview

This lab involved creating a user persona and developing a WordPress website focused on music, concerts, and ticket-buying experiences.



#### Tools Used

* Figma
* WordPress
* Local WP



#### Project Features

* Created a concert-ticket buyer persona.
* Developed a WordPress website with three main pages:

  * My Music
  * Concert Adventures
  * Ticket Tips
* Created a blog section containing three posts.
* Organized website content using static pages and blog posts.
* Designed consistent website navigation and layout.



#### Learning Outcomes

* Learned how user personas help guide design decisions.
* Gained experience building and organizing a WordPress website.
* Practised structuring website content for users.
