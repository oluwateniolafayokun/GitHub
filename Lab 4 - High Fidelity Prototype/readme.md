# Lab 4 – High-Fidelity Prototype



#### Overview

This lab involved designing a high-fidelity interactive prototype for a tourism website based on the Hidden Leaf Village (Konoha) from Naruto.



#### Tools Used

* Figma



#### Project Features

* Designed a tourism website showcasing locations within Konoha.
* Included locations such as Hokage Rock, Ichiraku Ramen, and the Ninja Academy.
* Created interactive navigation between different sections.
* Implemented a draggable image gallery using Smart Animate.
* Created an image lightbox that opens when an image is selected.
* Added a custom tap-to-reveal interaction.



#### Learning Outcomes

* Gained experience creating high-fidelity prototypes.
* Practised designing interactive website elements.
* Learned how to use Figma interactions and Smart Animate.
