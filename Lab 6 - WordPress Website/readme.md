# Lab 6 – APSS WordPress Website



#### Overview

This lab involved designing and developing a WordPress website for AIDS Programs South Saskatchewan (APSS), focusing on presenting information about its services in a clear and accessible way.

#### 

#### Tools Used

* WordPress
* Local WP

#### 

#### Project Features

* Created a Home page and an Our Services page.
* Developed three blog posts covering:

  * HIV \& STI Testing
  * Overdose Prevention \& Harm Reduction
  * Client Care \& Support
* Created consistent website navigation.
* Designed a header and footer for the website.
* Included desktop and mobile navigation layouts.

#### 

#### Learning Outcomes

* Gained experience developing a service-based website.
* Practised organizing information into clear website sections.
* Learned the importance of consistent navigation and responsive design.
